# Dataset Information

This project uses the publicly available Store Item Demand Forecasting dataset from Kaggle.

## Dataset Details
- Training records: 913,000
- Stores: 10
- Products: 50
- Historical period: 2013–2017
- Test records: 45,000

## Files
- train.csv: Historical sales records
- test.csv: Records for future sales prediction
- sample_submission.csv: Required prediction submission format

## Source
https://www.kaggle.com/competitions/demand-forecasting-kernels-only/data
